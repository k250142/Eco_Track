EcoTrack is a menu-driven Python console application that analyzes household electricity use, estimates cost, draws charts, classifies consumption with machine learning, processes energy notes with TF-IDF, gives rule-based saving tips and shows weather context from the Open-Meteo API.

## Setup (VS Code)

1. Install Python 3.11 or newer and open the `EcoTrack` folder in VS Code.
2. Open a terminal (Terminal > New Terminal) and run:

```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate        macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt
```

3. Pick the data subset (see "Data" below), then start the program:

```bash
python main.py
```

Use menu option **1** first (loads and validates the data), then any other option.

## Weather API

* Uses the free [Open-Meteo](https://open-meteo.com/en/docs) API. **No API key is needed**, so no secrets exist in the repository.
* Enter a place name (`Karachi`) or coordinates (`24.86,67.01`). Place names are resolved with the Open-Meteo geocoding API.
* HTTP status codes are checked. Successful responses are cached in `data/processed/weather_cache.json`; if the network is down, the cached copy is shown and marked as cached.
* Weather is context only and is not evidence of what caused past consumption.

## Method notes

* **Energy, not power:** the UCI file holds average power (kW) per minute. Hourly energy (kWh) = mean power of the valid minutes in the hour x 1 h. Hours with fewer than 45 valid minutes are dropped.
* **ML labels:** each hour is labelled high/low against the **median of the training hours only**; the same threshold is applied to the test data. Models predict the **next hour's** label from lagged consumption and calendar features. The split is chronological (first 80% train, last 20% test), the scaler is fitted on training data only, and a simple "repeat the current hour" baseline is printed for reference.

## Limitations and ethics

* Results describe only the selected data subset, which may not represent other households, regions or climates.
* Model scores depend on dataset size, class balance and feature quality.
* Cost figures and recommendations are estimates, not guaranteed savings.
* Household electricity data can reveal daily routines. Do not publish private records. The UCI dataset and Open-Meteo are used under their own terms. No credentials are stored.
